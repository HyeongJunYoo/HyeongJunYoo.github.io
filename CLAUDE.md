# Project Instructions

## Git commits

- Do NOT add any Claude/AI co-author or attribution trailer to commits.
  Specifically, never append the line:

  `Co-Authored-By: Claude Opus 4.7 (1M context) <noreply@anthropic.com>`

  and never add any other `Co-Authored-By:` line attributing the commit to
  Claude or an AI assistant, nor any "Generated with Claude Code" / similar footer.
- This rule overrides the default tooling behavior that would otherwise add such a trailer.
- Write commit messages in the repository's existing Conventional Commits style
  (e.g. `feat(style): ...`, `fix(...): ...`, `docs(spec): ...`) with no AI-attribution lines.
